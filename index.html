Room Watch Sync

Stop a film in one room, carry on in another. One pairing code for the whole house — no server, no account, nothing to keep running.

Kodi 19+ MIT licence No account Titles stay in the house

Install

  1. On each television, install the repository zip: repository.roomwatchsync-1.1.0.zip
  2. Settings → Add-ons → Install from zip file, pick that file. Kodi will ask you to allow installation from unknown sources the first time.
  3. Install from repository → Room Watch Sync Repository → Video add-ons → Room Watch Sync.
  4. Open the add-on. It asks one question: this is the first television (it creates a home and shows you a code) or join a home that already exists (type the code from the other television).

Updates arrive through the repository, so this is the only install you do. The add-on can also be installed directly from repository/plugin.video.roomwatchsync/ if you would rather not use the repository at all.

How it works

The pairing code is the whole configuration

Sixteen characters in Crockford Base32 — no I, L, O or U, because somebody reads it off one screen and types it into another. From it, three independent values are derived with HKDF-SHA256: the channel name, a key that turns a title into an opaque identifier, and a key that signs every message.

Titles never leave the house

A message carries an HMAC of the media's identity, a position in seconds and a timestamp. Not "The Sopranos S03E08". Each television resolves that opaque key against its own library, where the title already is — so there is no plaintext to protect, which is stronger than encrypting one.

Every television holds the whole state

The network is a transport, never a database. A television that was switched off missed a delay, not a fact: it asks on startup, and whoever is on answers.

Nothing to run, and an option if you want durability

The default channel is ntfy.sh, which needs no account and keeps a message for 12 hours — extended to about three and a half days by republishing each snapshot as delayed copies. For state that simply persists, server/worker.js is a thirty-line Cloudflare Worker: free, deployed once, no machine in the house.

Your pairing code is a password

Anyone who has it can read — and change — what this household has watched. Share it with the people you would let sit on your sofa, and never post it in a forum, an issue or a screenshot. If you think it leaked, create a new home and re-pair.
