# Room Watch Sync for Kodi

תוסף קוד פתוח שמסנכרן את נקודת הצפייה בין מכשירי Kodi באותו בית —
**בלי שרת, בלי חשבון ובלי שום דבר שצריך להשאיר דולק.**

עוצרים בטלוויזיה אחת, עוברים לאחרת, ופתיחת אותו סרט או פרק ממשיכה מהמקום
האחרון עם חזרה של 20 שניות. מסך **המשך צפייה** מרכז את הפריטים הפתוחים של כל
הבית — אבל רק את אלה שהטלוויזיה הזאת באמת יכולה לנגן.

דף ההתקנה והמידע: **<https://nemet360.github.io/kodi-room-sync/>**
כתב הוויתור המלא: [DISCLAIMER.md](DISCLAIMER.md) ·
[באתר](https://nemet360.github.io/kodi-room-sync/disclaimer.html)

## התקנה

1. בכל טלוויזיה, התקינו את ה-zip של המאגר:
   [`repository.roomwatchsync-1.1.0.zip`](https://nemet360.github.io/kodi-room-sync/repository.roomwatchsync-1.1.0.zip)
   (**Settings → Add-ons → Install from zip file**; בפעם הראשונה Kodi יבקש
   לאשר התקנה ממקור לא מזוהה).
2. **Install from repository → Room Watch Sync Repository → Video add-ons →
   Room Watch Sync**.
3. פתחו את התוסף. הוא שואל שאלה אחת:
   - **זו הטלוויזיה הראשונה** — נוצר בית חדש ומוצג קוד צימוד.
   - **להתחבר לבית קיים** — מקלידים את הקוד מהטלוויזיה האחרת.

זה הכל. אין כתובת שרת, אין token, אין פורט.

## גם כאן: התוספים של peno64

אחרי התקנת **Room Watch Sync Repository**, התוספים של peno64 מופיעים בתוכו לצד
שלנו — וביניהם `repository.peno64` עצמו, כך שאפשר להתקין את כל המאגר שלהם
מכאן בצעד אחד.

**שום קובץ שלהם אינו מאוחסן כאן.** קודי קורא את
[האינדקס של peno64](https://github.com/peno64/repository.peno64) ומוריד את
הזיפים ישירות מה-GitHub שלהם, כך שהם נשארים המפרסמים ועדכון שלהם מגיע ברגע
שהוא יוצא. העבודה שלהם לפי התנאים שלהם, אינה נבדקת או מאושרת כאן, והפרויקט
הזה אינו נושא באחריות לה.

הזיפ שלהם ישירות, באותו אופן כמו שלנו: <https://peno64.github.io/repository.peno64/repository.peno64-1.5.zip>
(מתארח ב-github.io שלהם, לא כאן). להתקנת המאגר שלהם בדרך המקורית: <https://peno64.github.io/repository.peno64/>

שני דברים הושמטו במכוון מההכרזה שלהם אצלנו, ושניהם ברמת ה-`<dir>` ולא ברמת
המאגר — בדיוק הסיבה שזה `<dir>` שני ולא עריכה של שלנו: אין `<checksum>`, כי
ה-`addons.xml.md5` שהם מפרסמים אינו תואם את הבייטים שהשרת שלהם מחזיר (נמדד
בשלוש התיקיות שלהם), והצהרה על checksum שלא יתאמת תגרום לקודי לדחות את
התיקייה; ואין `<hashes>`, כי הם לא מפרסמים hash לכל zip, ובקשה מקודי לאמת מול
קובץ שמחזיר 404 היא בדיוק ה"ההתקנה נכשלה" בלי סיבה שהמאגר הזה נתקל בו.

## קוד הצימוד הוא סיסמה

16 תווים ב-Crockford Base32 — בלי `I`, `L`, `O` ו-`U`, כי מישהו קורא אותו
ממסך אחד ומקליד אותו לשני. ההקלדה סלחנית: אותיות קטנות, רווחים, מקפים, ו-`O`
במקום `0` או `l` במקום `1` — כולם מתקבלים.

**כל מי שיש לו הקוד יכול לקרוא — וגם לשנות — מה הבית הזה צפה.** שתפו אותו רק
עם מי שהייתם מרשים לשבת על הספה שלכם, ואל תפרסמו אותו בפורום, ב-issue או
בצילום מסך. אם הוא דלף — צרו בית חדש וצמדו מחדש.

## איך זה עובד

- מהקוד נגזרים ב-HKDF-SHA256 שלושה ערכים בלתי תלויים: **שם הערוץ**, **מפתח
  פריט** שהופך זהות מדיה למזהה אטום, ו**מפתח חתימה**.
- על הקו נוסע HMAC של זהות המדיה, מיקום בשניות וחתימת זמן — **לא** "The
  Sopranos S03E08". כל טלוויזיה פותרת את המפתח האטום מול הספרייה **שלה**, שבה
  השם כבר קיים. אין טקסט גלוי להצפין, וזו תכונה חזקה יותר מהצפנתו.
- **כל הודעה חתומה.** ערוץ של 130 ביט לא ינוחש, אבל "לא ינוחש" אינו "אי אפשר
  לכתוב אליו" — ובלי חתימה, מי שראה את הערוץ היה יכול להריץ אחורה סרט של מישהו.
- **כל טלוויזיה מחזיקה את המצב המלא מקומית.** הרשת היא תעבורה, לא מסד נתונים:
  טלוויזיה שהייתה כבויה פספסה עיכוב, לא עובדה. בעלייה היא מבקשת, ומי שדולק עונה.

## ערוץ הסנכרון

ברירת המחדל היא **ntfy.sh** — בלי חשבון, בלי הרשמה, בלי כלום. הודעה נשמרת שם
12 שעות, ולכן כל snapshot מתפרסם גם כארבעה עתקים מושהים (+12h, +1d, +2d, +3d),
כל אחד נראה 12 שעות מרגע המסירה שלו. זה כיסוי רצוף של ~3.5 ימים.

למי שרוצה מצב שפשוט נשמר לנצח: [`server/worker.js`](server/worker.js) הוא
Cloudflare Worker של 30 שורות — חינמי, נפרס בפקודה אחת, בלי מכונה בבית. אחרי
הפריסה בוחרים ב**הגדרות → מתקדם → ערוץ הסנכרון → כתובת משלך** ומזינים
`https://<worker>.workers.dev/<הערוץ>`. שם הערוץ מוצג במסך הקוד.

אפשר גם להפנות ל-ntfy משלכם, או לכל כתובת שעונה ל-GET ול-PUT.

## פיתוח

```bash
python -m unittest discover -s addon/plugin.video.roomwatchsync/tests -v
python -m unittest discover -s tools/tests -v
python tools/build_repository.py      # בונה מחדש את repository/
python tools/build_disclaimer.py      # מרנדר DISCLAIMER.md ל-disclaimer.html
```

התוסף והטסטים שלו משתמשים **רק בספרייה התקנית** של פייתון. זו לא העדפה: Kodi
לא מגיע עם חבילות צד שלישי, ובמאגר התוספים הרשמי (2,327 תוספים ב-Omega) אין
שום ספריית הצפנה — רק `script.module.pyscrypt`. תלות כאן היא תלות שלטלוויזיות
אין.

`repository/` מקומט במכוון, כי GitHub Pages מגיש אותו ישירות מהבראנץ'. ה-CI
נופל אם בנייה מחדש משנה אותו ולא קומט — אחרת ה-zip שאנשים מתקינים אינו הקוד
שבקומיט.
