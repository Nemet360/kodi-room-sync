# Room Watch Sync for Kodi

תוסף קוד פתוח שמסנכרן את נקודת הצפייה בין מכשירי Kodi באותו בית.

עוצרים בטלוויזיה אחת, עוברים לאחרת, ורואים הודעת סנכרון קצרה. פתיחת אותו סרט או פרק מהספרייה ממשיכה מהמקום האחרון. מסך **המשך צפייה** מאפשר לקפוץ במהירות לפריטים האחרונים, עם חזרה ברירת־מחדל של 20 שניות.

## מה כלול

- שירות רקע ל-Kodi 19 ומעלה, ללא תלויות Python חיצוניות.
- סנכרון כל 15 שניות ובעצירה, סיום או יציאה מהנגן.
- התאמת סרטים ופרקים לפי מזהים חיצוניים, ובגיבוי לפי שם/שנה/עונה/פרק.
- עדכון נקודת החזרה בספריית Kodi המקומית.
- מסך וידאו פשוט של "המשך צפייה".
- שרת FastAPI קטן עם SQLite, אימות Bearer ו-Docker Compose.
- מאגר Kodi הניתן להתקנה ולעדכונים.

## התקנה מהירה

### 1. השרת

על מחשב, NAS או Raspberry Pi שנשאר פעיל בבית:

```bash
cp .env.example .env
# החליפו את WATCHSYNC_TOKEN במחרוזת ארוכה ואקראית
docker compose up -d --build
```

בדיקה:

```bash
curl http://SERVER-IP:8844/health
```

### 2. התוסף בכל טלוויזיה

1. הורידו והתקינו ב-Kodi את [`repository.roomwatchsync-1.0.0.zip`](https://raw.githubusercontent.com/Nemet360/kodi-room-sync/main/repository/repository.roomwatchsync/repository.roomwatchsync-1.0.0.zip).
2. בחרו **Install from repository → Room Watch Sync Repository → Video add-ons → Room Watch Sync**.
3. בהגדרות התוסף הזינו `http://SERVER-IP:8844`, את אותו token, ושם שונה לכל טלוויזיה.
4. הפעילו מחדש את Kodi. הודעת סנכרון קצרה תופיע לאחר החיבור.

אפשר גם להתקין ישירות את ZIP התוסף מתוך `repository/plugin.video.roomwatchsync/`.

## איך זה עובד

השרת שומר רק מטא־נתוני צפייה: מזהה תוכן, כותרת, נתיב מקור, משך ומיקום. הוא אינו מעביר וידאו, סיסמאות או קבצי מדיה. העדכון האחרון שהשרת קיבל הוא הקובע.

כל פריסת שרת מיועדת לבית אחד. המכשירים אינם צריכים לגלות זה את זה: בכל התקנת Kodi מזינים את אותה כתובת שרת ואת אותו token, והשרת הוא נקודת המפגש. קוד הפרויקט והמאגר הציבורי משותפים לכולם, אבל נתוני הצפייה נשארים בשרת הפרטי של כל בית.

שירות ציבורי מנוהל למספר בתים ידרוש שכבה נוספת של חשבונות, קודי צימוד ובידוד נתונים. ה־MVP אינו מפעיל שירות ענן כזה ואינו מערבב משקי בית.

הפעלה מהירה עובדת היטב כששני המכשירים רואים אותם נתיבי SMB/NFS או אותה ספריית Kodi. תוספי סטרימינג חיצוניים עלולים להחזיר כתובות זמניות; במקרה כזה סנכרון נקודת הספרייה עדיין עשוי לעבוד, אך קיצור הדרך אינו מובטח.

## פיתוח ובדיקות

```bash
python -m pip install -r server/requirements-dev.txt
pytest -q
python tools/build_repository.py
```

הארכיטקטורה וחוזה ה-API מתועדים ב-[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## אבטחה

מי שמחזיק ב-token יכול לקרוא ולעדכן היסטוריית צפייה. אין לחשוף את השרת לאינטרנט ישירות; לגישה מחוץ לבית השתמשו ב-VPN כגון Tailscale או ב-reverse proxy עם HTTPS.
